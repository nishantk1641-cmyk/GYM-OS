# GymOS 3D Website

A premium, responsive 3D-style SaaS landing page for GymOS.

## Files
- index.html — complete landing page
- style.css — responsive styling, 3D effects and visual system
- script.js — cursor glow, dashboard parallax, reveal animations
- assets/ — reserved for local images/assets

## Run
Open `index.html` directly in a browser. An internet connection is only needed for the Google Fonts import; the core page works without it.

## Customize
Search/replace:
- GymOS
- pricing
- copy
- colors in `:root`
- CTA links

The dashboard visual is built entirely with HTML/CSS/SVG, so there are no paid image assets or heavy 3D libraries.
